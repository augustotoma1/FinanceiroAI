# Ops Artifacts

Este diretório centraliza materiais operacionais que antes estavam espalhados na raiz do repositório.

## Estrutura
- `deploy/scripts/`: scripts utilitários de deploy, merge e inicialização.
- `deploy/blocks/`: blocos e anotações de deploy (txt).
- `deploy/deploy_blocks/`: conjunto de blocos shell usados em sequências de deploy.
- `troubleshooting/fixes/`: scripts de correção pontual.
- `troubleshooting/notes/`: anotações de troubleshooting.
- `legacy/`: snapshots legados de arquivos de código.

## Observações
- Estes artefatos foram organizados para manter a raiz do projeto limpa.
- Antes de executar scripts aqui, revisar conteúdo e ambiente alvo.
